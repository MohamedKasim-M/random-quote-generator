# 💭 Quote Generator

A simple and modern **Random Quote Generator** that fetches inspirational quotes from a public API and displays them dynamically.

This project was developed as part of **Task 16.2 – Quote Generator** using HTML, CSS, and JavaScript.

## ✨ Features

- 💭 Generate random quotes
- ✍️ Display quote author
- 🔄 Get a new quote with one click
- ⏳ Loading indicator
- ⚠️ Error handling
- 📱 Responsive design
- 🎨 Modern and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Async/Await
- DummyJSON Quotes API

## 🔗 API Used

**DummyJSON Quotes API**

API Documentation:

https://dummyjson.com/docs/quotes

Random Quote Endpoint:

```text
https://dummyjson.com/quotes/random
```
